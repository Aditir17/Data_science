# Data Science & Machine Learning Portfolio

Welcome to my Data Science and Machine Learning portfolio! This repository contains hands-on projects developed using Python, exploring data analysis, machine learning fundamentals, and deep learning techniques.

## Projects

### 1. CNN Flower Image Identification

**Technologies:** Python, TensorFlow, CNN, NumPy, Pandas, Matplotlib

**Overview:**

An image-classification project using Convolutional Neural Networks (CNNs) to identify and classify flower images into different categories.

**Key Concepts:**
- Image preprocessing and data preparation
- Convolutional Neural Networks (CNN)
- Model training and evaluation
- Image classification and prediction

### 2. Brain Tumor Identification

**Technologies:** Python, TensorFlow, CNN, NumPy, Pandas, Matplotlib

**Overview:**

A deep-learning project exploring brain tumor identification using MRI images through image classification techniques and Convolutional Neural Networks.

**Key Concepts:**
- MRI image preprocessing
- Image classification
- CNN architecture and model training
- Model evaluation and prediction

*Note: This project is for educational and research purposes only and is not intended for clinical diagnosis.*
